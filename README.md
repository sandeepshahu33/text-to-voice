# 🎙️ Text to Speech & Speech to Text Web App

A modern and interactive **Text to Speech & Speech to Text** web application built using **HTML, CSS, and JavaScript**. The application allows users to convert written text into natural speech and transform spoken words into text directly through the browser.

## 🚀 Live Demo

🔗 **Live Demo:** https://sandeepshahu33.github.io/text-to-voice/

## 📌 About the Project

This project demonstrates the practical use of **Web Speech APIs** to create a browser-based voice interaction experience.

Users can:

* 🔊 Convert text into speech using Text-to-Speech functionality.
* 🎤 Convert spoken words into text using Speech Recognition.
* 🎚️ Control speech settings such as voice, rate, pitch, and volume.
* 📝 Enter and edit text before converting it into speech.
* 📋 View recognized speech directly as text.
* 🖥️ Use the application through a clean and responsive interface.

## ✨ Features

* **Text to Speech** – Converts written text into spoken audio.
* **Speech to Text** – Converts microphone input into text.
* **Voice Selection** – Supports available browser voices.
* **Speech Controls** – Adjust rate, pitch, and volume.
* **Real-Time Recognition** – Displays recognized speech dynamically.
* **Responsive Design** – Works across desktop and mobile screen sizes.
* **Simple User Interface** – Clean and easy-to-use design.
* **Browser-Based** – No backend or external server required.

## 🛠️ Technologies Used

* **HTML5** – Application structure and semantic markup
* **CSS3** – Styling, layout, responsiveness, and UI design
* **JavaScript (ES6+)** – Application logic and Web Speech API integration
* **Web Speech API** – Text-to-Speech and Speech Recognition functionality

## ⚙️ How to Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/sandeepshahu33/text-to-voice.git
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd text-to-voice
```

### 3. Run the Application

Open `index.html` in a modern web browser.

For the best development experience, you can use the **Live Server** extension in VS Code.

## 🌐 Browser Compatibility

The application relies on browser-supported Web Speech APIs. Speech recognition support can vary depending on the browser and operating system.

For the most consistent experience, use a modern browser such as **Google Chrome**.
